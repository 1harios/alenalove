# 📸 Папка для фото без шифрования

Сейчас фото и видео Алёнки лежат в папке `media/` в зашифрованном виде (см. README.md в корне) — так их не видно посторонним в публичном репозитории.

Эта папка нужна, только если добавлять фото скриптом `add-photos.bat`: он кладёт сюда уменьшенные копии **без шифрования**
и заменяет список в `js/photos.js`. Если хочешь сохранить фото закрытыми — лучше пришли новые фото Claude.
