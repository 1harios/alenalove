# Alёnagram 🎂 — поздравление для Алёны

Мобильный сайт-сюрприз ко дню рождения Алёны (11.10.1995) в стиле историй Instagram.
Поздравляет Саша ❤️

## Что внутри

Сначала открывается **экран блокировки** с уведомлением «sasha опубликовал историю специально для тебя 💌».
Нажатие на уведомление открывает **истории**, после них можно погулять по **профилю** Алёны.

Ещё: строка «Ответить sasha…» с быстрыми реакциями, лайк ❤️, звук вкл/выкл, удержание пальцем — пауза, свайп вниз — закрыть.
В профиле — «Актуальное» (быстрый переход к любой игре) и сетка фото, по двойному тапу на фото ставится лайк.

Эмодзи везде в стиле iOS: на iPhone — родные, на Android и компьютере — картинки Apple (лежат в `assets/emoji`).
Сайт не зависит от внешних сервисов: шрифты, эмодзи и звуки — внутри проекта.

## 1. Добавить фотографии Алёны

Фото лежат у Саши на компьютере (`C:\Users\kkkar\OneDrive\Изображения\Алёна`), поэтому их нужно добавить один раз. Есть три способа — выбери любой.

### Способ А — автоматически (Windows, рекомендую)
1. Скачай проект: на GitHub нажми **Code → Download ZIP** и распакуй (или открой через GitHub Desktop).
2. Дважды кликни **`add-photos.bat`**. Скрипт:
   - возьмёт фото из папки `Изображения\Алёна` (если не найдёт — спросит, где они);
   - развернёт их правильно, уменьшит до 1600 px (сайт будет быстро грузиться) и **уберёт геометки** из файлов;
   - разложит по порядку съёмки в `photos/` и `photos/thumbs/` и запишет список в `js/photos.js`;
   - откроет сайт в браузере.
3. Загрузи на GitHub папки **`photos`** и **`js`** (Add file → Upload files → перетащи папки) или сделай commit в GitHub Desktop.

> Если Windows предупредит о скачанном файле — нажми «Подробнее → Выполнить в любом случае».
> Фото в формате HEIC (с iPhone) откроются, если установлены «Расширения для изображений HEIF» из Microsoft Store; иначе скрипт их пропустит.

### Способ Б — через сайт GitHub (без программ)
Загрузи фото прямо в папку `photos` репозитория (Add file → Upload files). На GitHub Pages сайт сам найдёт их.
Минус: фото будут «тяжёлыми», с геометками внутри. Поэтому лучше после загрузки попросить Claude: *«обработай фото в папке photos»* — он уменьшит их, повернёт, удалит геометки и заполнит `js/photos.js`.

### Способ В — вручную
Положи фото в `photos/` и перечисли их в `js/photos.js`:
```js
window.PHOTOS = [
  { src: 'photos/01.jpg', caption: 'Моя любимая улыбка 😍' },
  { src: 'photos/02.jpg', caption: 'Тот самый вечер 🌙', story: true },
];
```
- `caption` — подпись в истории;
- `story: true` — показать именно это фото в историях (иначе выберутся автоматически, `storyPhotoCount` штук);
- первое фото станет аватаркой и обоями экрана блокировки (можно указать другое в `js/config.js` → `avatar`).

## 2. Поменять тексты

Все тексты — в **`js/config.js`**: письмо, комплименты, купоны, предсказания, подписи к фото, даты, имена.
Эмодзи можно вставлять прямо в текст.

## 3. Посмотреть

Просто открой **`index.html`** двойным кликом — сайт работает и без интернета.
Удобно для проверки: `index.html?s=candles` откроет сразу нужную историю
(`intro`, `hb`, `poll`, `timer`, `feed`, `candles`, `photo-1`, `balloons`, `slider`, `coupons`, `cookie`, `ask`, `letter`, `final`).

## 4. Опубликовать и отправить ссылку

**GitHub Pages (бесплатно):**
1. Репозиторий → **Settings → Pages**.
2. *Source*: **Deploy from a branch**, ветка — та, где лежит сайт (например `main`), папка **/ (root)** → **Save**.
3. Через 1–2 минуты сайт будет по адресу **https://1harios.github.io/alenalove/**

Превью ссылки в Telegram/WhatsApp («У тебя 1 новая история 💌») берётся из `assets/og.jpg`.
Если адрес сайта другой — поменяй ссылку в `index.html` (строка `og:image`).

> ⚠️ На бесплатном GitHub Pages репозиторий должен быть **публичным** — значит, фото в нём сможет увидеть любой, кто найдёт репозиторий.
> Поисковики сайт не проиндексируют (стоит `noindex`). Если хочется приватности — сделай репозиторий приватным и подключи его к бесплатному
> [Netlify](https://www.netlify.com/) или [Cloudflare Pages](https://pages.cloudflare.com/) — они умеют публиковать приватные репозитории.

## Советы на день рождения

- Отправь ссылку ровно в 00:00 11 октября 🕛 — в шапке историй будет «N ч.» с полуночи.
- Звук: на iPhone при включённом беззвучном режиме мелодию не слышно — на первом слайде есть подсказка «🔊 Со звуком интереснее».
- Чтобы задуть свечи голосом, браузер спросит доступ к микрофону — это нормально. Без микрофона свечи гасятся пальцем.
- Фоновая музыка (необязательно): положи `mp3` в `assets/` и впиши в `js/config.js` → `music`.
