# Alёnagram 🎂 — поздравление для Алёнки

Мобильный сайт-сюрприз ко дню рождения Алёнки (11.10.1995) в стиле историй Instagram.
Поздравляет Саша ❤️

## Что внутри

Сначала открывается **экран блокировки** (обои — её фото) с уведомлением «sasha опубликовал историю специально для тебя 💌».

В профиле — «Актуальное» (IMVU, «Ты», «Мы», игры, письмо), сетка из всех фото и видео (новые сверху), лента с подписями; двойной тап — лайк.

Эмодзи везде в стиле iOS: на iPhone — родные, на Android и компьютере — картинки Apple (лежат в `assets/emoji`).
Сайт не зависит от внешних сервисов: шрифты, эмодзи и звуки — внутри проекта.

## 🔒 Фото и видео зашифрованы

Репозиторий публичный, поэтому фото и видео лежат в папке `media/` **в зашифрованном виде**: открыть их на GitHub нельзя.
Сайт расшифровывает их прямо в телефоне. Ключ **не хранится в репозитории** — он есть только в чате с Claude.

**На Vercel ключ лежит в настройках проекта, и ссылка на сайт — обычная, без ключа:**
1. Vercel → проект → **Settings → Environment Variables**.
2. Добавь переменную `MEDIA_KEY`, в значение вставь ключ → **Save**.
3. **Deployments** → последний деплой → **⋯ → Redeploy**.

При сборке `tools/vercel-build.js` записывает ключ в `js/key.js` и ставит в превью ссылки адрес сайта.

Если переменной нет (или сайт на другом хостинге), фото открываются по ссылке с ключом: `https://адрес-сайта/#k=КЛЮЧ`.
Часть после `#` не уходит на сервер, а телефон запоминает ключ после первого открытия.
Без ключа сайт тоже работает (с эмодзи вместо фото) и показывает подсказку «🔒 Фото и видео откроются по ссылке от Саши».

## Поменять тексты и подписи

- Все тексты — в **`js/config.js`**: письмо, комплименты, купоны, предсказания, история про IMVU, заголовки блоков фото, даты, имена.
- Подписи к фото — в **`js/photos.js`** (поле `caption`). Там же `story: 1` (блок «Самая красивая») и `story: 2` (блок «Это мы»).
- Эмодзи можно вставлять прямо в текст.

## Поменять или добавить фото

Проще всего — пришли новые фото Claude: он их уменьшит, повернёт, кадрирует, уберёт метаданные и **зашифрует тем же ключом**.

Есть и скрипт для Windows **`add-photos.bat`** (берёт фото из `Изображения\Алёна`, уменьшает, убирает геометки и пишет список в `js/photos.js`).
Учти: он кладёт фото в папку `photos/` **без шифрования** — в публичном репозитории их сможет увидеть любой — и заменяет текущий список фото
(прошлый сохранится в `js/photos.backup.js`).

## Посмотреть

- С фото: открой ссылку с ключом (после публикации, см. ниже).
- Без фото: просто открой `index.html` двойным кликом — сайт работает и без интернета.
- Удобно для проверки: `index.html?s=candles#k=КЛЮЧ` откроет сразу нужную историю
  (`intro`, `hb`, `poll`, `imvu`, `timer`, `feed`, `candles`, `b1-1`…`b1-5`, `balloons`, `slider`, `b2-1`…`b2-5`, `coupons`, `cookie`, `ask`, `letter`, `final`).

## Опубликовать и отправить ссылку

**Vercel (сайт сейчас там):** проект подключён к этому репозиторию, и каждое изменение на ветке `claude/interactive-birthday-site-alena-dgknfx` публикуется само примерно за минуту.
Адрес сайта — в Vercel: **Settings → Domains** (вида `alenalove.vercel.app`). Алёнке отправляй именно его: длинные адреса отдельных деплоев закрыты входом в Vercel.

Превью ссылки в Telegram/WhatsApp («У тебя 1 новая история 💌») берётся из `assets/og.jpg` — личных фото в нём нет; адрес картинки сборка на Vercel подставляет сама.
Поисковики сайт не проиндексируют (стоит `noindex`).

**GitHub Pages** тоже подойдёт: Settings → Pages → Deploy from a branch → эта ветка, папка **/ (root)**.
Там фото открываются только по ссылке с ключом (`#k=…`), а адрес в строке `og:image` в `index.html` нужно поменять вручную.

## Советы на день рождения

- Отправь ссылку ровно в 00:00 11 октября 🕛 — в шапке историй будет «N ч.» с полуночи.
- Звук: на iPhone при включённом беззвучном режиме мелодию не слышно — на первом слайде есть подсказка «🔊 Со звуком интереснее». Видео играет со звуком.
- Чтобы задуть свечи голосом, браузер спросит доступ к микрофону — это нормально. Без микрофона свечи гасятся пальцем.
- Фоновая музыка (необязательно): положи `mp3` в `assets/` и впиши в `js/config.js` → `music`.

## Устройство проекта

```
index.html          — разметка
css/style.css       — стили
js/config.js        — ⚙️ тексты и настройки
js/photos.js        — 📸 список фото и видео (с подписями) и «особые» кадры
media/              — зашифрованные фото и видео
js/slides.js        — истории и мини-игры
js/stories.js       — просмотр историй (прогресс, тапы, свайпы, видео)
js/app.js           — экран блокировки, профиль, лента фото
js/core.js          — эмодзи, даты, расшифровка фото; sound.js, fx.js — звуки и конфетти
assets/emoji/       — эмодзи Apple (160 px)
assets/fonts/       — шрифты Caveat, Pacifico, Unbounded (OFL)
js/key.js           — ключ к фото (пустой; на Vercel его записывает сборка)
vercel.json + tools/vercel-build.js — сборка на Vercel: ключ из MEDIA_KEY и адрес для превью
add-photos.bat + tools/add-photos.ps1 — добавление фото на Windows (без шифрования)
```
